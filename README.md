# 📱 Personalized BMI Monitoring & SMS Alerts

A Python-based BMI monitoring application that calculates Body Mass Index (BMI) and automatically delivers the result through SMS using the Twilio API.

## 🚀 Project Overview

This project combines a BMI calculator with API-based SMS automation to provide users with their BMI results in a convenient and user-friendly way.

## ✨ Key Features

- BMI calculation using user-provided information
- Automated BMI result generation
- SMS delivery of results
- Twilio API integration
- Automated workflow for sending notifications

## 🛠️ Technologies

- Python
- Twilio API
- API Integration
- Automation

## 🔄 Project Workflow

User Input  
→ BMI Calculation  
→ Result Generation  
→ Twilio API  
→ SMS Notification

## 🎯 Project Objectives

- Automate BMI calculation
- Provide a simple user-centric monitoring experience
- Integrate an external API for SMS delivery
- Demonstrate API integration and workflow automation
